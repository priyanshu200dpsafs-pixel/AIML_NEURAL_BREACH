### 1. Executive Summary & Core Mission

In modern Security Operations Centers (SOCs), "black-box" machine learning predictions create analyst fatigue, skepticism, and delayed incident triage. The mission of **Role 5 (XAI & Threat Intelligence)** is to demystify every inference generated by Neural Breach's models by delivering:

#### 2.1. Tree-SHAP (Shapley Additive Explanations)
- **Mathematical Basis:** For a tree ensemble model $f(\mathbf{x})$, SHAP attributes prediction payout $\phi_i$ to feature $i$ using classic cooperative game theory:
  $$\phi_i(f, \mathbf{x}) = \sum_{S \subseteq F \setminus \{i\}} \frac{|S|!(|F| - |S| - 1)!}{|F|!} \left[ f_x(S \cup \{i\}) - f_x(S) \right]$$
- **Implementation:** Implemented via `shap.TreeExplainer` directly on the frozen LightGBM (`supervised_lightgbm_primary.joblib`) and XGBoost models.
- **Latency & Exactness:** Tree-SHAP computes exact Shapley values in $< 5 \text{ ms}$ per flow, avoiding the sampling approximations of KernelSHAP.
- **Directional Impact:** Feature attributions explicitly declare impact direction:
  - `INCREASES_ATTACK_LIKELIHOOD` ($\phi_i > 0$ on attack class)
  - `REDUCES_ATTACK_LIKELIHOOD` ($\phi_i < 0$ on attack class)
  - `SUPPORTS_BENIGN_PROFILE` ($\phi_i > 0$ when target is Benign)

#### 2.2. LIME (Local Interpretable Model-agnostic Explanations)
- **Mathematical Basis:** Fits an interpretable sparse linear surrogate model $g \in G$ locally around the flow $\mathbf{x}$:
  $$\xi(\mathbf{x}) = \arg\min_{g \in G} \mathcal{L}(f, g, \pi_x) + \Omega(g)$$
- **Implementation:** Implemented via `lime.lime_tabular.LimeTabularExplainer` using a 25-row reference baseline matrix derived from benign training traffic.
- **Role:** Available as a user-selectable alternative (`explainer_type="lime"`) for independent verification and cross-validation against SHAP.

#### 2.3. Unsupervised Autoencoder Reconstruction Attribution
- **Challenge:** When a flow is classified as `Benign` by the supervised model but flagged as an outlier by the PyTorch Deep Autoencoder or Isolation Forest, standard tree attribution cannot explain the anomaly.
- **Solution:** Role 5 calculates the per-feature mean squared reconstruction error:
  $$e_j = (x_j^{\text{scaled}} - \hat{x}_j^{\text{scaled}})^2 \quad \text{where } \hat{\mathbf{x}} = \text{Decoder}(\text{Encoder}(\mathbf{x}))$$
- **Interpretation:** Features exhibiting the highest $e_j$ represent the exact network telemetry dimensions that breached normal baseline distributions, pinpointing potential zero-day exploits or stealthy beaconing.

### 3. Cybersecurity Domain Interpretation Engine

Raw mathematical weights (e.g. `Flow Duration = +0.342`) are unhelpful to a tier-1 SOC analyst under pressure. Role 5 maps numerical shifts into clear network security interpretations:

| Feature Name | Typical Attack Dynamics | Domain Translation Generated for SOC Analyst |
| :--- | :--- | :--- |
| **`Flow Duration`** | High in Slowloris/GoldenEye; Low in Probes | *"Prolonged flow duration indicative of connection-holding exhaustion (Slowloris/GoldenEye) or volumetric flood."* |
| **`Tot Fwd Pkts` vs `Tot Bwd Pkts`** | Unidirectional packet asymmetry | *"High forward packet volume sent toward target without proportional dialogue, common in unidirectional packet floods."* |
| **`Tot Bwd Pkts`** | Zero or near-zero replies | *"Severe response deficit (zero/near-zero backward packets) indicates server non-responsiveness, dropping, or one-way flood."* |
| **`Flow Byts/s` / `Flow Pkts/s`** | Extreme volumetric transmission | *"Massive byte/packet transmission rate indicative of high-throughput denial of service (e.g. HOIC or UDP flood)."* |
| **`SYN Flag Cnt`** | High initial handshake assertion | *"Elevated SYN flag assertions indicating TCP handshake flooding or distributed scanning probes."* |
| **`PSH Flag Cnt`** | High push buffer flush | *"Intensive PSH flag usage forcing immediate TCP buffer flush to the application layer, common in HTTP/L7 attacks."* |
| **`Init Fwd Win Byts`** | Zero / Near-zero advertised window | *"Near-zero forward initial TCP window size indicates handcrafted raw sockets or severe client buffer starvation."* |
| **`Init Bwd Win Byts`** | Zero advertised window return | *"Target host returned zero/near-zero window, indicating target socket buffer saturation and denial of service."* |
| **`Bwd Pkt Len Std`** | Response length irregularity | *"Wide variation in response packet sizes, reflecting heterogeneous server responses or payload exfiltration."* |
| **`Flow IAT Mean`** | Timing dilation / High jitter | *"Prolonged inter-arrival intervals indicating deliberate timing delays to evade signature-based threshold alerts."* |

### 5. Threat Prioritization & Transparent Scoring System

To eliminate arbitrary severity flags, Role 5 computes an **empirical, explainable composite priority score** ($0.0 \text{ to } 100.0$) using a transparent linear scoring formulation:

$$\text{CompositeScore} = \min\left(100.0, \; \max\left(0.0, \; B \times 0.50 + (C \times 100) \times 0.25 + A_{\text{bonus}} + V_{\text{impact}}\right)\right)$$

Where:
1. **Base Attack Severity ($B \in [0, 100]$):**
   - Infiltration: $95.0$ | SQL Injection: $90.0$ | Bot: $90.0$
   - DDoS (HOIC / LOIC-UDP): $85.0$ | DDoS LOIC-HTTP: $80.0$
   - DoS (GoldenEye / Hulk): $75.0$ | DoS (SlowHTTPTest / Slowloris): $70.0$
   - SSH-Bruteforce: $65.0$ | FTP-Bruteforce: $60.0$ | Web / XSS Brute Force: $60.0$
   - Unsupervised Anomaly (`SUSPICIOUS_ANOMALY`): $65.0$ | Benign: $0.0$
2. **Confidence Contribution ($C \in [0.0, 1.0]$):**
   - Directly incorporates the supervised model's calibrated class posterior probability.
3. **Dual-Model Anomaly Corroboration Bonus ($A_{\text{bonus}} \le 15.0$):**
   - $+15.0$ points if **both** Isolation Forest and Deep Autoencoder trigger simultaneously.
   - $+8.0$ points if either detector triggers.
   - $0.0$ points if neither detector indicates anomalous distribution shift.
4. **Volumetric & Flow Impact Factor ($V_{\text{impact}} \le 10.0$):**
   - $+5.0$ points if `Flow Byts/s` $> 1 \text{ MB/s}$ or `Flow Pkts/s` $> 10,000$.
   - $+3.0$ points if `Flow Duration` $> 60 \text{ s}$ (connection holding).
   - $+2.0$ points if forward packet volume $> 1,000$.

### 6. Actionable SOC Analyst Playbooks & Hunting Queries

Every alert output by Role 5 contains actionable triage instructions tailored to the attack category. Because the system is strictly **observe-only**, containment recommendations explicitly reinforce that automatic packet dropping is prohibited.

#### Sample Playbook: Infiltration (T1190 / T1068 / T1021)
- **Immediate Investigation Steps:**
  1. *Verify source IP host identity and check for recent vulnerability scan activity against target endpoint.*
  2. *Inspect target host endpoint logs (Windows EVTX Event ID 4688 / Sysmon Event ID 1) for abnormal child process spawning.*
  3. *Cross-reference LANL/internal telemetry to identify unauthorized lateral SMB, RDP, or SSH connections.*
  4. *Check for newly created user accounts or privilege escalation events (Event ID 4720, 4672).*
- **Observe-Only Containment Protocol:**
  - `OBSERVE-ONLY NOTICE: Automated inline blocking is disabled.`
  - `Alert SOC Tier 2 Lead immediately of suspected initial access / infiltration vector.`
  - `Prepare endpoint network isolation order (EDR host quarantine) pending human authorization.`
  - `Snapshot memory and running processes on the destination workstation for forensic analysis.`
- **SIEM & Hunting Queries Provided:**
  ```sql
  SELECT timestamp, src_ip, dst_ip, process_name, command_line 
  FROM endpoint_telemetry 
  WHERE dst_ip = '{dst_ip}' AND timestamp >= '{ts_window_start}' 
  ORDER BY timestamp ASC;
  ```
  ```kql
  Sysmon 
  | where EventID == 1 and Computer == '{target_host}' 
  | project TimeGenerated, Image, CommandLine, ParentImage
  ```
